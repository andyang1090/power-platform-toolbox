How do I import it?

In Microsoft Lists or SharePoint, choose New list → From CSV and upload the downloaded file. Keep the ListSchema line by avoiding resaving the CSV in Excel.

This file contains the schema and column headers. Import behavior can vary by tenant. Check internal names in column settings after import. Use the file to create a new list.

SharePoint encodes spaces and other special characters in internal names. The resulting name appears below the input. Use a shorter name if it exceeds 32 characters. Add site-dependent fields such as Lookup and Person after creating the list.
